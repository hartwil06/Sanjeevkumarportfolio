# Sanjeev Kumar · Portfolio

Lead UI/UX Designer portfolio. Static site: `index.html` plus images in the same folder.

## Publish on GitHub Pages
1. Upload everything in this folder to the root of a public repository.
2. Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.
3. The site goes live at `https://<username>.github.io/<repo>/` in a minute or two.

Note: the "Leave a note" form sends notes by email on GitHub (the live note wall only works on the Claude-hosted version).
