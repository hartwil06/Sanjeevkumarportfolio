01The problem

Getting a merchant live meant long forms, documents sent back and forth, and status updates over email. Applications arrived incomplete, reviewers chased missing details, and nobody, merchant or bank, could see where an application actually stood.

MerchantsBank operationsRisk & compliance

02What I designed

A guided application

One long form became a five-step flow that saves as you go, so merchants can stop and come back without losing anything.

Document checks up front

Clear file rules and instant feedback on uploads, instead of a rejection days later.

One status, both sides

A shared tracker shows the merchant what's pending and the ops team the same stage, cutting "any update?" emails.

An ops review console

A queue with ageing flags, documents side by side with the data, and approve or return with clear reason codes.
